# Smart Healthcare Application using XGBoost and Random Forest

An AI-powered healthcare application designed for intelligent disease prediction and clinical decision support using Machine Learning models such as XGBoost and Random Forest.

## Features

* Disease prediction using XGBoost and Random Forest
* Confidence-based diagnosis system
* Explainable AI using SHAP
* Patient management system
* Prescription and recommendation module
* Healthcare chatbot support
* PostgreSQL database integration
* REST API backend using FastAPI
* React + Next.js frontend
* Responsive dashboard and analytics
